    imgstrip {{VERSION}} ·
    • The picture itself stays. Faces, reflections, street signs and landmarks can still identify people and places. imgstrip never alters what the image shows.
    • Robust watermarks can survive. Marks built to outlast re-encoding (Digimarc, SynthID and similar) live in the pixels. imgstrip removes C2PA manifests, not content watermarks.
    • File names can leak. Names like IMG_20240517_133700 carry a date. Cleaned files keep the original name plus .clean; rename them before sharing if that matters.
    • Data hidden in the pixels can survive. Lossless cleaning keeps every pixel value, so a steganography payload stored in them stays unless Scrub least-significant bits is on. Deep scan looks for one first.
    • Lossy formats are re-encoded. JPEG, WebP, AVIF and HEIF lose a little quality. Keep JPEG data bit-exact avoids that for JPEGs, but keeps any data hidden in the JPEG coefficients.
    • Originals stay as they are. imgstrip never modifies or deletes them; securely erasing old copies is up to you.
